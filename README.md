# B. DESKRIPSI

Repository ini dibuat untuk memenuhi tugas pada mata kuliah
Algoritma dan Pemrograman, khususnya materi Pertemuan 03 tentang
seleksi dalam Python.

Pada pertemuan ini dipelajari bagaimana membuat program yang dapat
mengambil keputusan berdasarkan kondisi tertentu. Struktur seleksi
yang digunakan dalam Python antara lain:

1. `if`
2. `if-else`
3. `nested if`

Konsep seleksi digunakan ketika sebuah program harus menentukan
tindakan yang berbeda berdasarkan kondisi atau nilai yang diberikan
oleh pengguna.

Dalam tugas ini, konsep tersebut diterapkan melalui beberapa program
latihan sederhana dan satu program tugas utama, yaitu analisis
persamaan kuadrat.
